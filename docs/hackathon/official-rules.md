# Regras oficiais do Hackathon

Este documento resume as regras do evento que limitam o trabalho da CodeImpact. Ele não substitui o [regulamento oficial](https://github.com/SouJunior/hackathon/blob/master/3_regulamento_oficial_hackathon_soujunior.md).

## Contexto do evento

- O desafio é criar uma Landing Page criativa, persuasiva e de alto impacto focada no [Apoia.se da SouJunior](https://apoia.se/soujunior).
- O hackathon é voltado principalmente para profissionais juniores. Pessoas plenas e seniores atuam como mentoras.
- O período de desenvolvimento é de **11 a 25 de setembro de 2026**.
- As equipes devem ter de 2 a 10 integrantes e pelo menos uma pessoa júnior; uma equipe não pode ser formada apenas por mentores.
- Cada integrante deve estar apoiando a SouJunior no Apoia.se. Apoio a partir de **R$ 2,00** já é elegível.

## Regras de produção e participação

- Código e design submetidos devem ser produzidos durante os 15 dias do evento.
- Bibliotecas open source e frameworks são permitidos quando suas licenças permitirem o uso e houver os créditos necessários.
- O projeto deve ser open source e estar em um repositório público do GitHub com licença open source válida.
- A colaboração deve preservar espaço real para a participação de juniores.
- Respeito, inclusão, segurança psicológica e fair play são requisitos de participação.
- Submissões após o encerramento oficial não são avaliadas. O horário exato de corte será informado nos canais oficiais, especialmente no grupo de avisos do WhatsApp.
