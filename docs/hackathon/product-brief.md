# Briefing de produto — Landing Page Apoia.se

## Objetivo

Criar uma Landing Page criativa, persuasiva e de alto impacto para aumentar o apoio à SouJunior no Apoia.se. A experiência deve explicar a causa, demonstrar impacto real, mostrar transparência e levar o visitante ao apoio recorrente a partir de R$ 2,00.

A Landing Page é o produto principal. O ranking/mural de apoiadores é um mecanismo de engajamento, prova social e conversão; não é um produto separado.

## Requisitos obrigatórios do MVP

### Hero

- Responder rapidamente por que apoiar a SouJunior.
- Exibir o CTA principal direcionando para o Apoia.se.
- Deixar claro que é possível apoiar a partir de R$ 2,00.

### Causa e transparência

- Explicar por que a SouJunior precisa de apoio.
- Explicar para onde o dinheiro é destinado.
- Destacar infraestrutura, serviços e manutenção do ecossistema.

### Impacto real

Usar somente números oficiais ou verificados. Os dados atualmente fornecidos para este projeto são:

| Indicador | Dado autorizado | Observação |
| --- | ---: | --- |
| Mentores ativos | 35 | Usar como número informado. |
| Pessoas empregadas por meio da SouJunior | Mais de 50 | Não transformar em uma métrica diferente. |
| Projetos em desenvolvimento | 3 | Usar como fotografia do momento. |
| Membros | 120 | Confirmar atualização antes de publicar. |
| Apoiadores | 108 | O número pode variar; registrar a data de referência quando possível. |

Não usar números inventados de “pessoas impactadas”. A SouJunior informou que ainda não possui uma métrica oficial para isso.

### CTA e apoio

- Apresentar claramente a campanha oficial no Apoia.se.
- Reforçar contribuição recorrente.
- Distribuir CTAs claros ao longo da jornada, sem competir com a compreensão da causa.

## Jornada principal

```text
Entender a causa
  → ver impacto
  → entender transparência
  → perceber o apoio da comunidade
  → apoiar no Apoia.se
```

O conteúdo, os CTAs e o mural devem reforçar essa jornada, não desviá-la para uma experiência de ranking.
