# Submissão e README final

## Requisitos da entrega

- Repositório público no GitHub.
- Licença open source válida.
- README completo.
- Vídeo de demonstração com no máximo 5 minutos.
- Vídeo mostrando a interface, os principais recursos e a experiência do usuário.
- Submissão até o horário oficial de encerramento.
- Nenhum commit após a data e hora de corte. O horário exato será informado nos canais oficiais.

Consulte a [página oficial de submissão](https://github.com/SouJunior/hackathon/blob/master/8_submissao.md) antes de enviar a entrega.

## Conteúdo mínimo do README

O README final deve conter, no mínimo:

- descrição do projeto;
- problema;
- solução;
- diferencial da CodeImpact;
- screenshots ou demo;
- stack;
- instruções de execução;
- estrutura do projeto;
- decisões técnicas relevantes;
- acessibilidade;
- testes;
- integrantes e responsabilidades;
- licença.

Este arquivo registra o requisito; o README final não precisa ser escrito nesta tarefa.

## Checklist de revisão

- [ ] Repositório público e licença válida.
- [ ] README permite onboarding sem contexto privado.
- [ ] Demonstração mostra a jornada completa até o CTA do Apoia.se.
- [ ] Vídeo tem no máximo 5 minutos.
- [ ] Todos os commits estão dentro do período permitido.
- [ ] Os canais oficiais e a campanha apontam para URLs corretas.
- [ ] A equipe confirmou o horário de corte nos canais oficiais.
